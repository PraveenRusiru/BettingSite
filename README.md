# Betting Site

A **full-stack betting web application** that demonstrates modern backend and frontend development skills by combining secure authentication, data scraping, and a dynamic user experience.

---

## 🧠 Project Overview

This project is a full-stack web application built with **Spring Boot, JWT & OAuth2 authentication**, and a JavaScript-based frontend. The platform simulates a betting site where users can register, log in, and interact with core features such as betting management, data scraping, and email notifications.

Key technologies like **Spring Boot, MySQL, JSoup, and SMTP** are used to deliver robust backend services, while the frontend uses **HTML, CSS, JavaScript, and jQuery** for interactive user interfaces.

---

## ⚙️ Features

- 🔐 **Secure authentication** using JWT (JSON Web Tokens) and OAuth2  
- 📝 **User registration and login**  
- 📊 **Betting management system**  
- 🕸️ **Web data scraping** using JSoup  
- 📧 **Email notifications** via SMTP  
- 💾 **MySQL database** for persistent storage  

---

## 🛠️ Technology Stack

| Layer | Technologies |
|-------|--------------|
| Backend | Java, Spring Boot, JWT, OAuth2 |
| Frontend | HTML, CSS, JavaScript, jQuery |
| Data Scraping | Jsoup |
| Email Service | SMTP |
| Database | MySQL |
